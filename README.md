Sistema de Gestión Presupuestaria de Proyectos UCR - API

Descripción

Esta API permite la gestión centralizada y eficiente de los presupuestos de los proyectos de la Universidad de Costa Rica (UCR). Facilita la asignación, seguimiento y control de los recursos financieros, generando informes y alertas automáticas para optimizar la administración financiera de los proyectos universitarios.

Funcionalidades principales

- Creación y actualización de proyectos y partidas presupuestarias

- Registro y seguimiento de gastos asociados a cada proyecto

- Generación de informes financieros detallados

- Configuración y envío de alertas para el control presupuestario

- Gestión de usuarios y permisos

Tecnologías utilizadas

- Lenguaje de programación: C# (.NET Core)

- Frameworks: ASP.NET Core Web API, Entity Framework Core

- Base de datos: Microsoft SQL Server

- Autenticación y Seguridad: JWT (JSON Web Tokens)

- Otros: Swagger para documentación, Unit Testing con xUnit
